# Harness

The harness is the domain-neutral runtime and evaluation layer. It will own
sandboxing, model and tool policy, timeout and cost enforcement, artifact
capture, cleanup, assertions, graders, and run reports.

No runtime has been promoted here yet. Candidates remain under `experiments/`
until their interfaces and security behavior are stable.

See [Runtime and evaluation harness](../docs/architecture/runtime-and-evaluation-harness.md).
